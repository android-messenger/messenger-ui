# 003 — сценарий → тест

Каждая строка — сценарий из [spec.md](spec.md). Тест называется с номера сценария (`"2.1: …"`). Файлы — в `front/src/__path__/`. Столбец «Тест» заполняется тем PR, который пишет тест; проверка T304 падает, пока в слитой истории есть пустая ячейка.

«Сейчас» — что показывает сегодняшний код: **дефект** (есть тест в `__audit__`), **дефект, чтение** (теста нет), **нет** (поведения нет вовсе), **ок** (работает, теста на настоящих частях нет).
