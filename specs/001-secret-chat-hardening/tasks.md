# Tasks: Секретные чаты — закрыть оставшиеся находки в интерфейсе

**Input**: [spec.md](spec.md)

**Формат**: `[ID] [P?] [История] Описание`. `[P]` — можно делать параллельно с соседними: другие файлы, нет зависимости. Пути — от корня репозитория.

**Правила работы**

- Одна история — одна ветка от свежего `main` и один PR. Имя ветки указано у истории.
- Сначала тест, который показывает дефект на `main` и падает. Потом исправление.
- Перед PR: `npx vitest run`, `npx eslint` по изменённым файлам, `npx vite build`, `npm run build:app` (из `front/`). После истории 2 это делает CI.
- Задача отмечается `[x]` в том же PR, который её выполняет. Статус истории в `spec.md` обновляется там же.
- Слияние PR — без отдельного вопроса. Выкатка веб-образа и публикация APK — только по слову владельца.
- Что не проверено, пишется в PR прямо.
